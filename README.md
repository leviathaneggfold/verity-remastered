### 📦 Installation & Compatibility

Inside the downloaded ZIP archive, you will find mod files for **every supported Minecraft version** from 1.18 up to 1.21.11.

1. Go to the **[Releases page](../../releases/latest)**.
2. Click the **Download** button in the latest release description.
3. Extract the ZIP file and find the `.jar` that matches your exact Minecraft version (e.g., `verity-remastered-1.20.1.jar`).
4. Move ONLY that `.jar` file into your `%appdata%\.minecraft\mods` folder.
5. Launch Minecraft using the Forge profile.

### ❓ Frequently Asked Questions

**Is this an official update?**
No, this is an unofficial community remaster. We are fans of the original mod and wanted to bring it to modern Minecraft versions with improved stability.

**My antivirus flags the .jar file. Is it safe?**
Yes, it's a standard false positive. Because the mod modifies game files and uses custom AI hooks, Windows Defender may flag it. Add the file to your exclusions if needed.

**Does this work on Bedrock?**
No, this is a Java Edition exclusive mod, built for Forge.
